# Context hand-off — Data Doodle Tech
_Last updated: 2026-10-04_

## Goal
Build a multilingual short-form technical education brand explaining data engineering, AI, databases, distributed systems, software architecture and system design through high-quality doodle animation.

## Brand direction
- Working name: **Data Doodle Tech**
- Tagline: **Complex tech. Simply drawn.**
- Positioning: **Data, AI & systems — drawn simply.**
- Audience: data/software/AI engineers, architects, students and curious professionals.
- Personality: playful, clear, credible, approachable and visually memorable.
- Name availability/trademark clearance remains unverified; do not treat prior web screening as legal clearance.

## Format decisions
- 9:16 vertical master, target 1080×1920.
- Keep essential objects in a central safe area.
- Minimal English labels; visuals should work across EN/DE/HI.
- English canonical script; German and Hindi adaptations preserve meaning and beats, not literal wording.
- 30–60 seconds; default 50–60 seconds when the topic needs it.
- Audio is the master timeline; finalize narration before animation timing.
- Avoid mid-sentence cuts and text-heavy artwork.

## Workflow
Topic → research → learning outcome → hook → beat sheet → EN script → DE/HI adaptation → visual brief → doodle artwork → narration → animation → edit/export → metadata → publish → analytics → iteration.

## Quality rules
- One question and one learning outcome per video.
- Verify claims; record sources and caveats.
- Use natural spoken language and explain acronyms when practical.
- Use simple analogies without presenting them as literal implementation.
- Check spelling, arrows, overlap, clipping, contrast, mobile legibility and audio sync.
- One CTA at most.

## Platform strategy
YouTube: searchable title, unique concise description, relevant hashtags, playlist and strong retention.
Instagram: searchable display name, clear bio, conversational caption, relevant hashtags and accurate alt text.
Use a small set of highly relevant hashtags as an editorial convention, not an algorithm guarantee. Optimize for qualified reach.
