# Data Doodle Tech

**Complex tech. Simply drawn.**

A repeatable content-production system for short, visual explanations of data, AI, databases, distributed systems and software architecture.

## Promise
Make one complex technical idea visually obvious in 30–60 seconds, using clear narration and hand-drawn doodle animation.

## Production principles
- Vertical-first 9:16 master (1080×1920); keep key elements in a central safe area.
- Audio is the timing master. Finalize narration before animation timing.
- One video = one question, one learning outcome, one memorable mental model.
- Visuals teach; narration explains. Keep on-image text minimal.
- English is canonical; German and Hindi adaptations preserve the same teaching beats naturally.
- Reuse language-neutral artwork across languages wherever possible.
- Accuracy before cleverness; record sources and caveats.
- Optimize for relevant viewers, retention, saves, shares and returning audience—not vanity views.

## Quick start
1. Read `docs/CONTENT_STANDARD.md`.
2. Choose a topic from `docs/CONTENT_PLAN.md`.
3. Copy `templates/CONTENT_BRIEF.md` into `content/backlog/`.
4. Run `templates/MASTER_PROMPT.md` with your topic.
5. Generate artwork using `templates/DOODLE_IMAGE_PROMPT.md`.
6. Finalize EN/DE/HI narration, then animate to each language's audio.
7. Use `templates/PUBLISHING_CHECKLIST.md` and prepare platform metadata.
8. Track results in `templates/PERFORMANCE_LOG.csv`.

## Structure
- `docs/` — brand, editorial standards, growth strategy and topic plan.
- `templates/` — reusable briefs, prompts, checklists and metrics log.
- `content/backlog/` — ideas and work in progress.
- `content/published-ready/` — episode packages ready for production/publication.
- `assets/` — brand and visual assets.

Each episode should contain research notes, scripts in three languages, visual brief, image prompt, YouTube package and Instagram package. Store media in an `assets/` subfolder when useful.
