# Roadmap

## Phase 0 — Foundation (current)
- [x] Brand positioning and tagline
- [x] Vertical-first multilingual format
- [x] Topic-to-publication workflow
- [x] Reusable prompts and QA checklist
- [x] Two worked examples (trade-offs; OLTP vs OLAP)
- [ ] Verify handles, domains and trademarks
- [ ] Finalize avatar, banner and watermark

## Phase 1 — Launch library
- [ ] Prepare 8–10 episodes before launch
- [ ] Build reusable scene/animation templates
- [ ] Create EN/DE/HI voice and pronunciation guides
- [ ] Test exports on phone and both platforms
- [ ] Set up playlists and pinned Instagram posts

## Phase 2 — First 30 episodes
- [ ] Publish sustainably (suggested starting point: 3 quality videos/week)
- [ ] Cover data foundations, databases, distributed systems and AI
- [ ] Review analytics weekly; identify winning topics/hooks
- [ ] Build sequels around strong audience response

## Phase 3 — Production efficiency
- [ ] Visual grammar library (icons, arrows, metaphors)
- [ ] Multilingual script QA and pronunciation glossary
- [ ] Automate episode folder creation and metadata validation
- [ ] Build a performance dashboard from the CSV log

## Phase 4 — Distribution
- [ ] Adapt selected episodes into LinkedIn carousels/posts
- [ ] Explore YouTube multi-language audio tracks if eligible
- [ ] Build a searchable episode website/index
- [ ] Create downloadable visual notes for high-performing topics

## Phase 5 — Long-term moat
- [ ] Recurring characters and recognizable visual metaphors
- [ ] Learning paths and topic playlists
- [ ] Expand successful shorts into longer explainers

Do not increase volume until accuracy, mobile legibility, narration quality and production repeatability are reliable.
