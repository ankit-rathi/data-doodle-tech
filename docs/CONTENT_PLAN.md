## Prioritization
Score each topic 1–5 for audience demand, practical value, visual explainability, accuracy within 60 seconds and sequel potential. Prefer high scores; split topics that need too many prerequisites.

## Content ladder
For each topic: beginner definition → how it works → architecture → trade-offs → failure modes → production considerations.
